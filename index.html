FAQ

Questions

Is OneEngine completely free to use?

Yes. OneEngine is licensed under the Apache License 2.0. There are no royalties, subscription tiers, or splash screen requirements.

What programming languages are supported?

C++20 is used for engine core systems and performance critical gameplay loops. LuaJIT 2.1 is fully embedded for rapid scripting, game rules, and hot-reloadable prototypes.

Does it include physics and audio out of the box?

Yes. OneEngine includes a fast 2D/3D collision detection pipeline and a low-latency spatial audio mixer built directly into the runtime.

Can I run dedicated multiplayer servers?

Yes. The engine can be compiled in headless mode with oneengine build --server, yielding an ultra-light 4MB server binary capable of hosting 64 players on minimal VPS hardware. (Size and player count are design targets.)

Where do I report a bug or ask a question?

Open an issue on GitHub Issues (opens in a new tab). Release notes for every build are on the changelog.
