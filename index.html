FROM ZERO TO DEDICATED SERVER

Gameplay lives in sandboxed Lua systems with full access to the ECS world and the netcode layer. This is real Helion script — no pseudocode, no hand-waving.

CTRL+S hot reloads everything
systems/combat.lua — helion 1.4.2 
-- spawn a plasma bolt whenever a player fires
local Combat = helion.system("combat", { "Transform", "Blaster" })
 
function Combat:update(dt, world)
  for e in world:each(self.query) do
    if input.pressed(e, "fire") then
      world:spawn(Projectile, { from = e.Transform, speed = 220 })
      net.broadcast("fx_muzzle", e.id)  -- replicated to all 64 clients
    end
  end
end
 
$ helion serve --dedicated --tick 128
