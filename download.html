Download OneEngine Store

Windows 10 and 11, 64-bit. Installers are published on GitHub Releases.

Open GitHub Releases Read the changelog
  1. Download the installer It saves into your Downloads folder as OneEngine-Store-Setup-<version>.exe. A .sha256 file next to it on GitHub lets you check the download.
  2. Run it Choose an install folder. Windows may show a SmartScreen notice because the installer is not code-signed yet: choose More info, then Run anyway.
  3. Create your account Open OneEngine Store and create an account or sign in. Browsing the catalog works now; game downloads and play arrive in a later update.
